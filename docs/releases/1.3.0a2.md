# Keydial Commander 1.3.0a2 — Ubuntu package preview

An easier installation path for Ubuntu 26.04: download one package, let APT
resolve runtime dependencies, then explicitly open Commander to start remapping.
This remains a prerelease while physical-device and graphical-session checks
are outstanding.
**Clean Ubuntu installation remains unqualified:** the rootfs harness failed
while configuring Ubuntu's systemd. Archive, extracted runtime and foreign-root
package transactions passed; those are narrower checks.

| Download | Use |
| --- | --- |
| `huion-keydial-mini-driver_1.3.0~a2-1_all.deb` | Ubuntu 26.04 package, built UI and desktop window. Start here. |
| `huion_keydial_mini_driver-1.3.0a2-py3-none-any.whl` | Managed Python environments; does not install system access rules or GTK. |

```bash
sudo apt install './huion-keydial-mini-driver_1.3.0~a2-1_all.deb'
keydial-commander --start-service
```

Installation never starts or enables remapping. Closing the window leaves
remapping active; `keydial-commander --stop-service` stops it. Login startup is
an explicit `systemctl --user enable huion-keydial-mini-user.service` choice.
Upgrades/removal stop active vendor-managed instances before changing files,
and preserve profiles and user-local overrides. Existing manual installations
need the migration steps in the guide.

The package retains the previous preview's output ownership, macro cancellation,
neutral recovery and validation behavior. New checks cover native archive paths,
installed metadata/UI, lifecycle stop failures and explicit startup failures.
The exact measured installation and regression results appear in the verification
record. No host service or physical device is used for those checks.

Clean-rootfs evidence does not establish graphical window/login behavior, udev
permissions or Bluetooth/USB operation. Other distributions remain unqualified;
the [1.3.0a1 manual Linux bundle](https://github.com/the3dcoder/KeydialCommander/releases/tag/v1.3.0a1)
remains available. Earl's existing project and commit identity is preserved.
